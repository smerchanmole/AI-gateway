GUÍA RÁPIDA DE INSTALACIÓN
==========================

Este fichero es una chuleta para terminal. README.md es la documentación
canónica y explica arquitectura, seguridad, YAML, Ollama, Cloudera y capacidad.

1. Crear y activar el entorno aislado:

   python3 -m venv .venv
   source .venv/bin/activate

2. Instalar exactamente las dependencias del proyecto:

   python -m pip install --upgrade pip
   python -m pip install -r requirements.txt

3. Crear `.env` a partir de `.env.example` y rellenar, como mínimo:

   LITELLM_MASTER_KEY=<clave larga y aleatoria del gateway>
   OPENAI_API_KEY=<sólo si se usan modelos OpenAI>

4. Revisar `config.yaml`. Nunca edites `runtime/active_config.yaml`: es una
   copia generada automáticamente.

5. Arrancar el panel:

   ./start.sh

   Si Cloudera ejecuta directamente "python app.py", el propio módulo instala
   requirements.txt antes de cargar FastAPI y las demás dependencias externas.
   Un fallo de pip cancela el arranque y muestra la causa en el log de sesión.

6. Abrir https://127.0.0.1:8081 y pulsar «Arrancar».

El panel escucha en 127.0.0.1:${CDSW_APP_PORT:-8081}. Las aplicaciones
consumidoras llaman al gateway OpenAI-compatible en
http://127.0.0.1:${CDSW_READONLY_PORT:-8090}/v1 usando LITELLM_MASTER_KEY.
Cloudera define ambas variables automáticamente y publica ambos servicios por
HTTPS. En local se usan los fallbacks y el panel genera un certificado HTTPS.
